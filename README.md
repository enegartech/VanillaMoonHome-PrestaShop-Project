# VanillaMoon E-commerce Store

## Project Overview

VanillaMoon is a bilingual e-commerce store project built with PrestaShop.

The project focused on e-commerce setup, store customization, product management, visual identity design, and responsive layout optimization.

**Note:** The online store is no longer hosted at its original domain. This repository serves as a portfolio and documentation of the project.

## Project Workflow

- Custom domain and hosting setup
- PrestaShop installation and initial configuration
- Removal or deactivation of unnecessary default elements
- Store structure setup
- Product addition and management
- Product image and information upload
- Separate USD and IRR pricing configuration
- Product catalog creation
- Product category and subcategory organization
- Persian and English language configuration
- Custom VanillaMoon logo design
- Custom visual identity development
- Brand color customization
- Homepage and navigation customization
- Banner, button, link, and label styling
- AI-assisted banner and product image creation
- PrestaShop module configuration
- Contact form activation and email delivery testing
- Dedicated store email setup
- User registration and login configuration
- Legal and informational page customization
- Shipping method configuration
- Standard and express delivery setup
- Default carrier configuration
- Responsive layout optimization
- Three-product-per-row mobile layout
- Desktop layout preservation
- Final visual testing across screen sizes

## Visual Identity

The store's visual identity was designed around four main colors:

- Gold
- Cream
- Black
- White

The logo, homepage, banners, buttons, links, and other interface elements were customized to match the brand identity.

## Responsive Design

The product layout was optimized for mobile devices, displaying three products per row while preserving the desktop layout.
