VanillaMoon E-commerce Store

Project Overview

VanillaMoon is a customized bilingual e-commerce store developed with PrestaShop.

This project includes the setup, configuration, design customization, product management, and responsive optimization of an online store.

• Custom domain acquisition
• Hosting setup

• Store structure setup
• Product addition and management

• Separate USD and IRR pricing setup
• Product catalog creation
• Product category and subcategory organization
• Persian and English language setup
• Custom VanillaMoon logo design
• Custom visual identity design
• Gold, cream, black, and white brand color customization
• Homepage customization
• Menu, banner, button, link, and label customization
• AI-assisted banner and product image creation

The VanillaMoon store uses a custom visual identity based on:

• Gold
• Cream
• Black

The logo, homepage, banners, buttons, links, and other visual elements were customized to match the brand identity.

Responsive Design

The product layout was optimized for mobile devices.

The mobile version displays three products per row, while the desktop layout remains preserved.
